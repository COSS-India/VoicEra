This is the no-terminal path. Everything here is done by clicking buttons in the dashboard: creating an agent, testing it, adding a phone number, running a campaign, uploading documents.

<Note>
If you are the one setting VoicEra up for the first time, that one-time step still needs a terminal — see [Install and run](../quickstart/install-and-run). Once it's running, hand the web address to whoever will use it day to day and start here instead.
</Note>

## What you need before you start

Someone technical needs to have:

1. Started VoicEra (see [Install and run](../quickstart/install-and-run)).
2. Given you the dashboard's web address — usually something like `http://localhost:3000` for a local install, or a company URL for a shared one.
3. Told you the AI providers already connected — or given you the API keys to connect your own (covered in [Sign up and get set up](sign-up)).

If you have all three, open that address in a browser and start with [Sign up and get set up](sign-up).

## The five things you'll learn to do

| Page | What you'll be able to do |
| --- | --- |
| [Sign up and get set up](sign-up) | Create your account and connect the AI services your agent will use. |
| [Create your first agent](create-an-agent) | Build a phone agent by answering questions in a step-by-step wizard — no config files. |
| [Test and call with your agent](make-a-call) | Talk to your agent from your browser, then give it a real phone number. |
| [Run a calling campaign](run-a-campaign) | Upload a list of phone numbers and have your agent call all of them. |
| [Everyday tasks](everyday-tasks) | Upload documents your agent can answer from, check call history, invite teammates. |

## If something isn't working

Every page below ends with a short "if this doesn't work" section. For anything else, see [Common problems](../troubleshooting/common-issues) or ask whoever manages your VoicEra installation — they have access to logs you don't.
